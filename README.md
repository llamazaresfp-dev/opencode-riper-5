# 🚀 RIPER-5 OpenCode Project Template

Plantilla de proyecto para OpenCode con el **workflow RIPER-5** completamente configurado.

## ✨ Qué incluye esta plantilla

| Componente | Descripción |
|------------|-------------|
| **7 Agents RIPER-5** | research, spec, innovate, plan, validate, execute, update-process |
| **9 Hooks Funcionales** | Inicialización, bloqueo scout, privacidad, state management, etc. |
| **Control de Acceso** | Whitelist de comandos permitidos en `.opencode/permissions.json` |
| **Estructura RIPER-5** | Carpetas `process/general-plans/` y `process/features/` listas para usar |

## 📦 Cómo Instalar

### Opción 1: Clonar este template directamente

```bash
git clone <URL-DE-TU-REPOSITORIO> nuevo-proyecto/
cd nuevo-proyecto
git init
opencode
```

### Opción 2: Crear repo desde GitHub

1. Ve a tu repositorio en GitHub
2. Haz clic **Use this template** → **Create a new repository**

## 🎯 Uso Recomendado

Perfecto para:
- ✅ Nuevos proyectos de OpenCode
- ✅ Proyectos que requieren workflow RIPER-5
- ✅ Plantillas CLI con estructura profesional

| Archivo | Propósito |
